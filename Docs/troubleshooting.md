# Troubleshooting

반복해서 발생하는 문제와 해결 방법을 기록합니다.

## Rule

- 같은 문제가 두 번 이상 나오면 이 문서에 기록합니다.
- 원인과 해결 방법을 분리해서 작성합니다.
- 임시 해결책이면 `Workaround`라고 표시합니다.
- 해결 후 관련 설정이나 코드 위치를 함께 남깁니다.

## Template

```md
## 문제 제목

- Date: YYYY-MM-DD
- Area: Client / Server / Renderer / Build / Asset / Network
- Symptom: 어떤 현상이 발생했는가
- Cause: 원인
- Solution: 해결 방법
- Related File: 관련 파일
- Note: 추가 메모
```
