# Asset List

외부 에셋의 출처, 라이선스, 사용 위치를 기록합니다. 포트폴리오와 발표 자료에 사용하기 위해 반드시 관리합니다.

## Policy

- 출처가 불명확한 에셋은 사용하지 않습니다.
- 라이선스가 프로젝트 목적에 맞는지 확인합니다.
- 수정한 에셋은 원본과 수정본을 구분합니다.
- 에셋을 추가하면 이 문서를 함께 업데이트합니다.
