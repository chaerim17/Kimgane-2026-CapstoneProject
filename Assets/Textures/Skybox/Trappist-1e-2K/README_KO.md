# TRAPPIST-1e 2K 큐브맵

각 면 2048×2048인 BC7 DDS 큐브맵입니다. 아래 파일명은 제작에 사용한 PNG 원본 6면을 가리킵니다.

| 순서 | 파일 | 방향 |
| --- | --- | --- |
| 0 | px_right.png | +X / 오른쪽 |
| 1 | nx_left.png | -X / 왼쪽 |
| 2 | py_up.png | +Y / 위 |
| 3 | ny_down.png | -Y / 아래 |
| 4 | pz_front.png | +Z / 앞 |
| 5 | nz_back.png | -Z / 뒤 |

Direct3D 큐브맵 방향 기준입니다. 측면은 +Y가 위, +Y 면은 -Z가 위, -Y 면은 +Z가 위입니다.
원본 PNG에서 DDS를 다시 만들 때는 위 순서대로 면을 넣으세요. 파일별 임의 회전이나 수평 반전은 필요하지 않습니다.
각 면은 90도이며 공통 경계 광선에서 샘플링하여 12개 경계의 픽셀을 맞췄습니다. manifest.json에 경계 쌍과 반전 방향을 기록했습니다.

## 게임용 DDS

`trappist-1e-skybox.dds`는 2048×2048 6면과 밉맵 12단계를 담은 `BC7_UNORM` DDS 큐브맵입니다. 원본 PNG는 위 표의 순서로 DDS에 들어갑니다.
밉맵은 선형 색 공간에서 축소하고 맞닿는 변과 모서리의 색을 맞췄습니다. BC7 압축 후 최상위 밉의 경계에서 측정한 채널 차이는 평균 0.13/255, 최대 7/255입니다.

## 별 위치

[HYG 4.1](https://github.com/astronexus/HYG-Database/tree/c7f7f883fe678cc7680169a50ccd7dcc49b060ce/hyg)의 3차원 별 위치를 TRAPPIST-1 관측 위치로 옮겼습니다.
[NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/overview/TRAPPIST-1)의 적경 346.6263919도, 적위 -5.0434618도, 거리 12.42988881pc를 사용했습니다.
[JWST 표적 정보](https://www.stsci.edu/jwst/phase2-public/2589.pdf)의 위치 epoch 2015.5에 맞춰 HYG의 속도 성분으로 별 위치를 전파했습니다.
선택된 별 25,724개(재계산 겉보기등급 7.5 이하)를 2K 해상도에 직접 렌더링했습니다. 태양도 한 개의 별로 들어갑니다.
밝기와 별색은 게임에서 보이도록 압축했습니다. 실제 에셋에는 별자리 선·이름·지면·행성이 없습니다.

## 생성 이미지와 정확도의 범위

은하수의 확산광 질감은 내장 image_gen 도구로 생성하고 실제 은하 좌표계에 배치했습니다. 생성 원본의 해상도는 (1774, 887)이며 확산광은 보간했습니다.
별 자체는 2K 면 위에서 원본 카탈로그 위치로 직접 그렸으므로 전체 저해상도 이미지를 늘린 결과가 아닙니다.
모든 면은 동일한 천구와 각도 기준 별빛 커널을 공유합니다. 원본 PNG에서 12개 면 경계의 최대 채널 차이는 0/255입니다.
카탈로그 측정 오차가 있는 정적 근사입니다. 행성 표면의 위도·경도·방향은 정해지지 않았으며 +Y는 지구 적도 좌표계의 천구 북쪽 기준입니다.
불확실한 거리(카탈로그 100000pc 표식)의 별은 원래 지구 기준 각도와 밝기를 유지합니다.
대기·성간소광 변화·광행차·변광성 위상·모항성·동일 행성계의 다른 행성은 구현하지 않았습니다.
기존 지구 별자리의 별 구성원은 보존되지만 가까운 별의 위치가 달라져 별자리 모양은 달라집니다. 표의 별자리 약어는 원래 지구 기준 카탈로그 식별용입니다.
