# 생성 출처와 이용 범위

- 외형 시안: 이 대화에서 내장 imagegen으로 새로 생성한 밀폐 헬멧형 사이보그.
- 3D 메시와 기본 PBR 텍스처: Hyper3D Rodin Gen-2.5의 공식 공개 평가 키를 이용한 1회 생성 결과. 개인 API 키나 유료 계정은 사용하지 않았고 구매도 하지 않았다.
- 원본 생성 이후 Blender에서 크기 정규화, LOD, 사용자 지정 리그와 미리보기 동작, OBJ·FBX·DX 스키닝 데이터, 파생 텍스처와 충돌 TXT를 구성했다.
- CGTrader 제품 이미지에서 인체 비례와 외형 디테일의 목표 수준을 참고했으며, 판매 모델 파일을 구매·다운로드·변환한 것이 아니다. 해당 제품의 Epic 스켈레톤, 얼굴 블렌드셰이프, 무기나 라이선스가 이 파일에 포함되지 않는다.

이 결과는 외형과 엔진 연동을 평가하기 위한 시제품이다. 공개 평가 키 사용만으로 상용 배포 권한이 확보되었다고 표시하지 않는다. Hyper3D 공식 안내는 상용 사용 범위가 요금제와 이용 조건에 달린다고 설명한다. 상용 게임 또는 자산 재판매에 사용하려면 해당 서비스에서 그 사용 범위를 확인해야 한다.
