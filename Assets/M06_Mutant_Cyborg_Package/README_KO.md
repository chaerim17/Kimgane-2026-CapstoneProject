# M06 감염된 장갑 사이보그

기존 P02 플레이어가 생체 감염에 지배당한 적 캐릭터다. 사용자가 요청한 저그에 감염된 마린의 방향에 맞춰 밀폐 헬멧과 군용 장갑을 남기고 왼쪽 어깨·팔·목·가슴·허벅지에 비대칭 생체 조직을 조형했다. 붉은 보랏빛 살점, 갈색 외골격과 곡선형 발톱, 장갑 틈으로 이어지는 힘줄, 소수의 황록색 포자낭을 구분한다. 기존 M05의 전신 외피를 대체한 별도 버전이다.

2026-10-11 손 수정: 기존 왼쪽 사이보그 손과 괴물손의 겹침을 없앴다. 기존 장갑과 손목 끝 메시를 제거하고 새 살점 손바닥·손가락·발톱만 남겼다. 손바닥은 전완 본에서 왼손 본으로 가중치가 전환되며 손가락은 왼손 본에 연결된다. 손가락과 발톱의 단면 방향을 곡선을 따라 연속적으로 연결해 굽힘 부위의 틈을 줄였다. 오른쪽의 둥근 덧견갑을 제거해 기존 분절형 어깨 장갑이 드러난다. 수정 전 패키지는 backups/M06_before_handfix_20261011_2216에 보존했다.

손 방향·리그 수정: 괴물손의 손등은 캐릭터 왼쪽 바깥(+X), 오른손 손등은 오른쪽 바깥(-X), 양손 엄지는 캐릭터 정면(-Y)을 향한다. 왼손 메시를 이 방향에 맞춰 새로 배치했고 오른손은 기존 메시 안으로 뼈를 옮겼다. 양손 5개 손가락에 각각 3관절을 두어 총 52본으로 확장하고 가중치를 다시 적용했다. 기존 32본 스켈레톤과 인덱스가 같지 않으므로 FBX 또는 스킨·스켈레톤·동작 JSON을 같은 수정본으로 함께 교체한다. 손가락 개별 관절 굽힘과 엔진 스킨 행렬의 결과를 검사했다. 손 리그 수정 전 패키지는 backups/M06_before_hand_rig_20261011_2257에 보존했다.

실제 Blender 메시를 수정한 작업이며 새 외부 3D 생성은 호출하지 않았다. 기본 인체·복장 메시와 원래 텍스처는 기존 Rodin 평가 생성 P02에서 이어졌다. 출처와 이용 조건은 LICENSE_NOTES_KO.md를 참고한다. 이전 P02·M03·M04·M05와 졸업작품 프로젝트는 수정하지 않았다.

DDS와 밉맵은 사용자가 제작하도록 PNG로 제공한다. 노멀·ORM·AO는 sRGB로 읽지 않는다. Normal_DX/GL 선택은 엔진 TBN 규약에 따른다. 노멀·금속성·발광을 표시하려면 해당 텍스처를 셰이더에 연결해야 한다.

## DirectX12 정적 TXT 적용

TXT는 기존 <Frame>: / <Mesh>: / <Positions>: / <Normals>: / <Indices>: 구조다. 미터 단위, 왼손 좌표계, +Y 위/+Z 정면, 발바닥 원점으로 이미 변환했다. Z·삼각형 순서·UV V를 다시 반전하지 않는다.

UV는 <TextureCoords0>:에 저장했다. 마지막으로 확인한 프로젝트 TXT 로더는 이 항목을 읽지 않아 UV를 (0,0)으로 채웠다. 텍스처를 표시하려면 이 항목을 읽어 Mesh::Vertex::uv로 전달하고 재질을 연결한다. 프레임 이름에 따른 정점 색은 텍스처 확인 시 흰색으로 설정한다. 이 에셋 작업에는 엔진 코드와 적 AI 수정이 포함되지 않는다.

OBJ는 기존 로더의 Z 반전·삼각형 순서 반전을 전제로 하며 UV V는 이미 반전했다. FBX는 일반 RH +Y 위/-Z 정면과 Blender 기본 UV다. 스킨 JSON은 엔진 LH +Y 위/+Z 정면과 V 반전 UV로 변환했다. JSON 행렬은 행 배열에 담은 열 벡터 규약이므로 DirectXMath 행 벡터 계산에는 전치한다. 최종 스킨 행렬에는 역바인드가 이미 반영되어 있다.

## 리그와 충돌

자체 52개 본, 정점당 최대 4개 정규화 가중치, Idle·Walk·Run·Swipe·Hand_Flex 시제품 동작이다. 손가락 이름은 Finger1~4와 Thumb이며 각 _02/_03 본이 연결된다. 손·손가락의 로컬 Z축은 손등 방향, 로컬 X축은 굽힘 축이다. Epic 스켈레톤 호환이나 얼굴 블렌드셰이프는 포함하지 않는다. 최종 공격 동작은 별도 제작해야 한다.

충돌은 프로젝트 box 형식이다.

```text
box M06_Mutant 0.000000 1.025000 0.000000 0.430000 1.025000 0.350000 0.000000 0.000000 0.000000
```

전체 0.86×2.05×0.70m의 몸통 중심 이동용 근사 상자다. 뻗은 팔·발톱·돌기까지 감싸는 상자나 부위별 피격 판정은 아니다.
