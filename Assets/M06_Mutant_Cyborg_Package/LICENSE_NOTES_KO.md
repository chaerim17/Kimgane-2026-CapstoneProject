# 원형과 변이 작업의 출처

- 원형: 같은 작업 폴더의 `player_survivor_v2` P02 사이보그. 2D 시안은 내장 imagegen으로 생성했고, 원형 3D 메시와 기본 PBR 텍스처는 Rodin Gen-2.5의 공개 평가 키로 생성했다.
- 이번 작업: 기존 Blender 메시를 수정하고 새 외골격·돌기·신경 조직·손톱·가슴 조직을 구성했다. 텍스처는 기존 맵을 변형하고 새 부위용 아틀라스를 만들었다. 이번 변이 작업을 위해 외부 3D 서비스에 새로 생성 요청하거나 유료 결제하지 않았다.
- 사용자 참고 이미지와 추가로 요청한 스타크래프트 감염된 마린은 생체 감염·장갑·갑각이 섞이는 외형 방향에 활용했다. 다른 캐릭터 메시나 텍스처를 다운로드하거나 변환하지 않았다.

이 모델은 기존 평가 생성물의 파생 작업이다. Blender에서 수정했다고 원형의 이용 조건이 사라지거나 추가 사용 권한이 확보되는 것은 아니다. 공개 평가 키 문서에는 평가·테스트용이라는 안내가 있으나 졸업작품 최종 제출·전시의 허용 범위를 별도로 확인받은 상태는 아니다. 상업적 배포 권한을 확보했다고 표시하지 않는다.
