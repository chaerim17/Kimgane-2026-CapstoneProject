# S-07 OBJ — 현재 DirectX 12 로더용 UV 변환본

**OBJ의 모든 UV를 `(u, 1-v)`로 변환했습니다. 로더와 셰이더에서는 V를 추가로 반전하지 않습니다.** 원본 OBJ는 `supply_crate/obj/`, 이 버전은 `supply_crate/obj_dx/`에 별도로 보관했습니다.

## 프로젝트에 적용

1. ZIP 안의 `obj/` 폴더를 프로젝트의 `Assets/S07_Supply_Crate_OBJ_Package/obj/`에 덮어씁니다. 파일명이 같으므로 현재 모델 경로를 유지할 수 있습니다.
2. 현재 만들어 둔 `textures/S07_BaseColor.dds` 등은 그대로 사용합니다. 이 ZIP은 OBJ 교체용이며 텍스처를 포함하지 않습니다.
3. 로더 또는 셰이더에 `v = 1-v` 처리를 추가했다면 제거합니다. 이번 파일에는 이미 그 변환이 적용됐습니다. 2026-09-27 확인한 현재 코드에는 추가 V 반전이 없으므로 그대로 읽으면 됩니다.
4. 프로그램을 다시 실행해서 모델을 다시 로드합니다.

이번 작업은 모델링 폴더의 변환본 생성까지입니다. 프로젝트 안의 파일과 DDS, 로더 코드는 직접 수정하지 않았습니다.

## 변환 범위

| 단계 | 본체 | 뚜껑 | 합계 삼각형 |
| --- | --- | --- | ---: |
| LOD0 | S07_Body_LOD0.obj | S07_Lid_LOD0.obj | 2,660 |
| LOD1 | S07_Body_LOD1.obj | S07_Lid_LOD1.obj | 1,464 |
| LOD2 | S07_Body_LOD2.obj | S07_Lid_LOD2.obj | 696 |
| LOD3 | S07_Body_LOD3.obj | S07_Lid_LOD3.obj | 308 |

`vt`의 V 값만 변경했습니다. 정점 위치·노멀·삼각형 인덱스·U 값·부품 피벗·단위는 원본과 같습니다. 위치/노멀은 기존과 같은 오른손 Y-up OBJ 좌표입니다. **현재 ObjLoader의 `(x,y,-z)` 변환과 삼각형 순서 `(0,2,1)` 변환은 유지**합니다. UV 방향과 좌표계의 좌우 반전은 별개입니다.

본체의 부모 기준 위치는 `(0,0,0)`, 뚜껑은 닫힌 상태 `(0,0.64,0)`, 열린 상태 `(0,1.27,0)`입니다. 단위는 미터이며 모든 LOD가 동일합니다.

## 텍스처·편집 안내

현재 DDS와 기존 PNG의 픽셀 방향을 그대로 사용하며 이미지 자체를 뒤집지 않습니다. 밉맵도 다시 만들 필요가 없습니다. MTL은 기존 PNG 경로를 유지하며, 현재 게임처럼 DDS를 코드에서 지정해 연결하면 됩니다. 현재 게임의 BaseColor 연결 외에 노멀·ORM 등 추가 맵을 사용하는 기능은 엔진에서 별도로 구현합니다.

이 버전은 상단이 V=0인 샘플링에 맞춘 OBJ입니다. **Blender 기본 재질로 그대로 열면 무늬가 뒤집혀 보일 수 있습니다.** Blender에서 편집할 때는 원래 `.blend` 또는 `obj/` 원본을 사용합니다. `preview_dx_uv.png`는 실제 변환 OBJ를 다시 불러온 뒤, 재질에서 DirectX의 UV 방향을 모사하여 확인한 기본색 전용 이미지입니다. 게임 실행 화면은 아닙니다.

`validation.json`에는 8개 파일의 UV 변환·삼각형 수·원본 유지 검증 결과를 기록했습니다. `assembly.json`에는 V가 미리 반전됐다는 정보와 기존 배치·재질 정보를 함께 저장했습니다.
